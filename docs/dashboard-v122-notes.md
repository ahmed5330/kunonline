# Dashboard v122 UX

- Executive pulse consolidates orders, counted revenue, net profit/margin, confirmation, delivery and Real ROAS.
- Duplicate top-level KPI cards for actual order cost, ad spend and the mislabeled margin/net-profit card are removed from the overview while their values remain available in the relevant detailed sections.
- Repeated per-section period controls and period chips are removed; the global period toolbar remains the single source of time context.
- Trend summary replaces repeated absolute totals with first-point-to-last-point movement for orders, revenue, net profit and ad spend.
- The ads campaign strip is removed because the AI advertising analysis already provides the deeper campaign breakdown.
- The AI KPI strip is removed because the same advertising KPIs already exist in the ads section.
- Analytical hierarchy: overview → trends → finance → ads → operations → shipping → AI.
- No API, database, order, finance, or ad-calculation logic is modified.
