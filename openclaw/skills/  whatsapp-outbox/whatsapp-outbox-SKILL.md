# إرسال رسائل الواتساب التلقائية — كن أونلاين

الـ skill ده منفصل تمامًا عن `konline-orders` (اللي بيستقبل أوردرات من جروبات واتساب). الـ skill ده شغلته **إرسال** رسائل — مش استقبال.

## الفكرة

نظام كن أونلاين بيحط رسالة في طابور (`whatsapp_outbox`) في حالتين:
1. **أوردر جديد اتسجّل** (من أي مصدر — يدوي، إيزي أوردرز، واتساب) → رسالة تأكيد فيها المنتج والإجمالي والعنوان وكود الطلب
2. **أوردر اتحوّل لـ"جاري الشحن"** → رسالة تنبيه بالشحن

شغلتك إنك تسحب الرسايل دي وتبعتها بنفس رقم الواتساب المتصل بيك، وتأكّد للنظام إنك بعتّها.

## الإعداد

نفس ملف `.env` بتاع `konline-orders`:
```
KONLINE_URL=https://app.kun-online.com
INGEST_TOKEN=...
```

**مهم جداً:** كل أمر `curl` لازم يتسبقه `source ~/konline/.env &&` في نفس السطر (زي كل الأمثلة تحت) — من غيرها، `$INGEST_TOKEN` هيبقى فاضي.

## الخطوات — كرّرها كل ٢-٥ دقايق

### ١. اسحب الرسايل المعلّقة

```bash
source ~/konline/.env && curl -sS -H "Authorization: Bearer $INGEST_TOKEN" "$KONLINE_URL/api/whatsapp/outbox"
```

الرد بيرجع Array فيه لحد ٥٠ رسالة، كل واحدة بالشكل ده:
```json
{
  "id": "WAO-XXXXXXXXXX",
  "client_id": "c2",
  "order_id": "احم200",
  "phone": "01012345678",
  "message": "مرحباً محمود...",
  "kind": "confirm",
  "created_at": "2026-08-19T10:00:00.000Z"
}
```

لو الـ Array فاضي، مفيش رسايل معلّقة — استنى للدورة الجاية.

### ٢. ابعت كل رسالة

لكل عنصر في القائمة، ابعت نص `message` مباشرة لرقم `phone` (طبّع الرقم لصيغة دولية زي ما بتعمل في `konline-orders`: يبدأ `0` → استبدله بـ `20`).

**استخدم قدرتك على إرسال رسالة واتساب مباشرة لرقم فردي (Direct Message)** — مش جروب. لو مفيش عندك أداة إرسال مباشر لرقم فردي وبس بترسل لجروبات، بلّغ في اللوج ومتحاولش تكمل.

### ٣. أكّد النتيجة للنظام

**لو الإرسال نجح:**
```bash
source ~/konline/.env && curl -sS -X POST -H "Authorization: Bearer $INGEST_TOKEN" \
  "$KONLINE_URL/api/whatsapp/outbox/<ID>/sent"
```

**لو الإرسال فشل** (رقم غير صحيح، مثلاً):
```bash
source ~/konline/.env && curl -sS -X POST -H "Authorization: Bearer $INGEST_TOKEN" \
  "$KONLINE_URL/api/whatsapp/outbox/<ID>/failed"
```

**مهم:** لازم تأكّد لكل رسالة (نجحت أو فشلت) — لو ماأكّدتش، الرسالة هتفضل ظاهرة في الطابور وهتحاول تبعتها تاني في الدورة الجاية، يعني ممكن تتكرر على العميل.

## قواعد عامة

1. **متبعتش نفس الرسالة مرتين.** لو رسالة معينة نجح إرسالها بس فشل تأكيد `/sent` (مشكلة شبكة مثلاً)، ممكن تظهر تاني في السحب الجاي — قبل ما تبعتها تاني، لو شايف إنك بعتها فعلاً قريب، أكّد `/sent` بس من غير إعادة إرسال.
2. **الحد الأقصى للسحب الواحد ٥٠ رسالة** — لو عندك عدد أكبر معلّق، هيتقسم على أكتر من دورة تلقائي.
3. **ده استخدام غير رسمي لواتساب** (اتصال عادي مش WhatsApp Business API) — لو لاحظت أي تحذير أو قيود من واتساب على الرقم، وقف الإرسال فورًا وبلّغ.
4. **رسائل خارج أوقات معقولة** (نص الليل مثلاً) — لو الرسالة معلّقة من وقت متأخر، ابعتها عادي وقت ما تشتغل الدورة، مفيش داعي تأجيلها لوقت تاني.
